# Getting started

Install the fontkit package into your project’s packages directory. Import the module you need: `FontKit`.

Start with the [API contracts](api.md) for usage, constraints, and platform limitations. The [typed API](reference.md) lists constructors, each parameter and its default, properties, and return values directly from source.
